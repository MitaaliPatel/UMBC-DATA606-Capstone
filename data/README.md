# data

This folder is intentionally left empty in the repository. The datasets used in this project are too large to store on GitHub and must be downloaded separately.

## Datasets

### 1. FEMA OpenFEMA Individual Assistance Data

| Detail | Info |
|--------|------|
| File name | `fema_assistance_yearly_summary.csv` |
| Source | FEMA OpenFEMA |
| Download | https://www.fema.gov/about/openfema/data-sets |
| Rows | 3,794 |
| Columns | 6 |
| Time period | 2019-2022 |

Key columns: `Year`, `State`, `county`, `total_applicants`, `housing_assistance_amount`, `total_assistance_amount`

### 2. US Census Bureau American Community Survey (ACS)

| Detail | Info |
|--------|------|
| File name | `acs_county_social_economic.csv` |
| Source | US Census Bureau ACS 5-Year Estimates |
| Download | https://data.census.gov |
| Rows | 16,106 |
| Columns | 8 |
| Time period | 2019-2022 |

Key columns: `full_name`, `total_population`, `median_income`, `poverty_count`, `state`, `county`, `Year`, `poverty_rate`

### 3. Master Merged Dataset

| Detail | Info |
|--------|------|
| File name | `master_disaster_data.csv` |
| Source | Generated by running the master merge notebook |
| Rows | 3,611 |
| Columns | 12 |

This file is produced by merging the two datasets above at the county-year level. Run the master merge notebook in the `notebooks/` folder to generate it.

### 4. Engineered Dataset

| Detail | Info |
|--------|------|
| File name | `master_engineered.csv` |
| Source | Generated by running `models/train_models.py` |

This file is produced automatically when you run the training script. It contains all the original columns plus engineered features like `assistance_per_capita`, `vulnerability_index`, and log transforms.

## Setup Instructions

1. Download `fema_assistance_yearly_summary.csv` from the FEMA link above
2. Download `acs_county_social_economic.csv` from the Census link above
3. Place both files in this `data/` folder
4. Run the notebooks in order to produce `master_disaster_data.csv`
5. Run `python models/train_models.py` to produce `master_engineered.csv`

## Note on Data Quality

One row in the master dataset has a corrupted `median_income` value of -666,666,666. This row is automatically removed in the training script and Streamlit app using the filter `df[df['median_income'] > 0]`.
