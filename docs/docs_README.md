# docs

This folder contains project documentation for the FEMA Disaster Resource Allocation capstone project.

## Files

| File | Description |
|------|-------------|
| `report.md` | Full project report covering background, data, EDA, modeling, results, and conclusions |

## Report Sections

The report follows the DATA606 capstone template and covers:

1. Background and research questions
2. Data sources and data dictionary
3. Exploratory data analysis findings
4. Feature engineering
5. Model training and evaluation
6. Streamlit web application
7. Conclusion and limitations
8. References
